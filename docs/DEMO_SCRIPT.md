# Family Steward Demonstration Script

Target length: 2 minutes 30 seconds.

## 1. The problem - 20 seconds

Families repeatedly coordinate forms, appointments, renewals, schedules, and
preferences across disconnected systems. Most assistants turn that work into
another inbox. Family Steward prepares routine work quietly and interrupts only
when household-owner authority is required.

## 2. The morning scan - 35 seconds

Open the Carter family demonstration. Show three fictional situations:

- a school form with known fields already prepared;
- an appointment brief prepared while a school-pickup conflict is surfaced;
- renewal options compared before asking the owner to choose.

Point out that routine preparation and owner decisions are visibly separated.

## 3. Memory without exposure - 25 seconds

Search for the family's morning communication preference. Explain that QMD
discovers candidates locally, while Family Steward verifies the pinned file,
digest, event identity, and current state before returning a public-safe result.
No raw path, score, internal identifier, or private corpus reaches Aster.

## 4. AWS agent review - 35 seconds

Run the explicit fictional cloud review. Explain that Bedrock AgentCore hosts a
single bounded Strands entrypoint. Aster receives only the deterministic
fictional decision packet and uses Amazon Nova Micro to explain what needs the
owner. Refreshing the page never spends credits.

## 5. Human authority - 20 seconds

Approve one fictional decision. Show that the original event remains preserved
and an append-only outcome supersedes it. Aster never signs, purchases, sends,
or decides on behalf of the household owner.

## 6. Close - 15 seconds

Family Steward reduces household administration without asking a family to
trust an autonomous black box. It stays quiet for routine work, remembers the
source of truth, and asks a human exactly when human authority matters.
