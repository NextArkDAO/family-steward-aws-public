# Privacy and responsible AI

Family Steward is a fictional demonstration, not a live household service.
All Carter family events are synthetic. Do not import actual health, financial,
school, identity or family records into this prototype.

Local memory and approval outcomes stay in the local server process. QMD runs
locally against a dedicated fictional corpus. Retrieval is candidate discovery,
not authority; source and state checks determine whether a result may be shown.

The hosted reviewer receives only an allowlisted action and reads its packaged
fictional fixture. AWS processes the model request; normal AWS service logging
may apply. No claim of zero retention by AWS is made.

The model explains; deterministic code and the human own authority. This demo
does not sign forms, send messages, change calendars, make purchases or payments.
Approval is a local simulation with an appended outcome, not an external action.

No real-world impact, time-savings benchmark, or production privacy certification
is claimed. Agent explanations may be wrong; the source-backed decision cards
remain authoritative. The interface renders model output as text, not HTML.

This local demonstration has no multi-user authentication and must not be exposed
as a public service. The AWS endpoint is IAM authenticated. Production use would
require consent, household access controls, retention/deletion policy, encrypted
durable storage, threat review, and evaluation with real users.
