# Project Contract

## Identity

- Product: Family Steward
- Track: Everyday Agents
- Representative: Dwayne Swinton
- Organization: DemonFox Collectibles LLC dba NextArk
- Build window opened: 2026-08-21

## User

Busy households that repeatedly coordinate forms, schedules, appointments,
renewals, and commitments across more than one person.

## Promise

Handle routine preparation quietly and surface only the smallest decision the
household owner must make.

## Non-goals

Family Steward is not a general companion, financial executor, medical agent,
identity archive, permanent conversational memory, or autonomous form signer.

## Originality boundary

This is a newly created Apache-licensed project. It may use public frameworks,
official starter patterns, and disclosed AI coding assistance. It must not copy
private code, data, prompts, fixtures, or proprietary memory logic from another
NextArk project.

## Definition of the first working slice

Given a fictional household packet, Family Steward must:

1. prepare safe known work;
2. identify whether owner authority is required;
3. remain quiet when no decision is required;
4. issue one bounded decision when authority is required;
5. preserve the original event and append the owner's outcome.
